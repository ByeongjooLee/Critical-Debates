# 1930년대 기교주의 논쟁 분석 파이프라인

논문 4장에서 명시한 다섯 분석 도구를 실제 코퍼스에 적용하기 위한 Python 스크립트.

```
텍스트언어학 개념          →    텍스트마이닝 도구
──────────────────────────────────────────────────
미시 결속                       접속 표지 분석 (5범주, NF)
어휘적 응결                     빈도 (NF) · 핵심어 (LL) · 공기어 (MI)
메타담화                        BHR (강조-완화 비율)
```

---

## 1. 설치

Python 3.8 이상.

```bash
pip install -r requirements.txt
```

의존성은 `kiwipiepy>=0.18.0`만 사용 (한국어 형태소 분석). 나머지는 표준 라이브러리.

---

## 2. 코퍼스 준비

다음 폴더 구조로 텍스트 파일을 정리하세요. 인코딩은 UTF-8.

```
corpus/
├── kim/                    # 김기림 텍스트
│   ├── 1933_modernist.txt
│   ├── 1935_method.txt
│   └── ...
├── im/                     # 임화 텍스트
│   ├── 1935_critique.txt
│   └── ...
└── park/                   # 박용철 텍스트
    ├── 1935_inspiration.txt
    └── 1936_technique.txt
```

- 폴더명 `kim`, `im`, `park`은 *권장*. 다른 이름도 가능하나 `CRITIC_NAMES` 매핑을 수정해야 함.
- 파일명은 자유 (`연도_제목.txt` 형식 권장 — 향후 시기별 분석 확장 시).
- 한국어 본문만 포함. 메타데이터·각주·페이지 번호는 제거.

---

## 3. 실행

### 기본 실행

```bash
python gigyo_analysis.py --corpus corpus/ --output output/
```

출력 폴더에 다음 세 파일 생성:

| 파일 | 내용 |
|---|---|
| `results.json` | 모든 분석의 정량 결과 (정규화된 JSON) |
| `report.txt` | 사람이 읽기 위한 텍스트 요약 |
| `dashboard_with_data.html` | 시각화 대시보드 (템플릿 사용 시) |

### 참조 코퍼스(『조선일보』등) 포함

```bash
python gigyo_analysis.py --corpus corpus/ --output output/ --reference chosun_ilbo.txt
```

참조 코퍼스는 단일 .txt 파일 또는 .txt 파일들이 든 폴더.

### 대시보드 템플릿 사용

```bash
python gigyo_analysis.py --corpus corpus/ --output output/ \
                        --template gigyo_analysis_dashboard.html
```

`gigyo_analysis_dashboard.html`(앞서 만든 대시보드)을 템플릿으로 사용하면, 출력 HTML의 `<script>` 블록에 `window.REAL_ANALYSIS_DATA`로 실제 분석 결과가 주입됩니다. 브라우저 콘솔에서 확인 가능.

⚠️ 주의: 템플릿의 차트는 모의 데이터로 그려져 있습니다. 실제 수치는 `results.json` 또는 `report.txt`를 참조하세요.

### ModernKoreanSubword 토크나이저 (선택)

김병준(2024)의 ModernKoreanSubword 모델이 있다면:

```bash
python gigyo_analysis.py --corpus corpus/ --output output/ \
                        --sw-tokenizer modern_korean.model
```

모델이 없으면 기본 Kiwi가 사용됩니다 (1930년대 국한문혼용체 분석에는 정확도가 다소 떨어질 수 있음 — 4장의 한계 절 참조).

## 4. 어휘·표지 사전 수정

`gigyo_analysis.py` 상단의 다음 변수들을 직접 수정하여 분석 어휘를 확장하세요.

| 변수 | 용도 |
|---|---|
| `KEY_TERMS` | 빈도 분석 대상 어휘 (~30개) |
| `STOP_WORDS` | 핵심어 분석 제외 어휘 (기능어·대명사) |
| `CONNECTIVES` | 접속 표지 (5범주) |
| `BOOSTERS` | 강조 표지 (메타담화) |
| `HEDGES` | 완화 표지 (메타담화) |
| `COLLOCATION_TARGETS` | 공기어 분석 대상 어휘 |

특히 **근대 한국어 비평 어법** 특유의 표지를 추가하는 것이 분석의 핵심입니다. 코퍼스를 정독하면서 발견되는 표지를 위 변수에 직접 추가하세요.

예시:
```python
HEDGES = [
    "아마도", "어쩌면",       # 현대어
    "미상불", "대저",         # 근대 비평 어법
    "한 듯", "ㄴ 셈이",       # 근대 추측 어미
    # ... 사용자가 직접 추가
]
```

## 5. 분석 도구의 작동

### ① 빈도 분석 (`analyze_frequency`)
- `KEY_TERMS`의 각 어휘에 대해 비평가별 천 어절당 빈도(NF) 산출.
- 원시 빈도(`count`)도 함께 보고.

### ② 핵심어 분석 (`analyze_keywords`)
- *대수우도비(LL)*로 통계적 변별 어휘 식별.
- 두 종류 분리 보고:
  - `critic_vs_critic`: 한 비평가 vs 나머지 두 비평가 합 (탐색적)
  - `critic_vs_reference`: 비평 전체 vs 참조 신문 (장르 변별)
- *효과 크기(% DIFF)*를 LL과 함께 보고.

### ③ 공기어 분석 (`analyze_collocation`)
- *상호정보량(MI)*으로 핵심 어휘의 공기 패턴 추출.
- 윈도우 ±5 어절, 최소 공기 빈도 3회 (유령 공기어 통제).
- 텍스트 경계 보존하여 cross-text contamination 방지.

### ④ 접속 표지 분석 (`analyze_connectives`)
- 5범주(대조·원인결과·첨가·예시환언·요약결론) 천 어절당 빈도.
- 다어절 표지(예: "다시 말해")는 원문 부분문자열로, 단일 표지(예: "그러나")는 토큰으로 검색.

### ⑤ BHR (`analyze_bhr`)
- Booster-Hedge Ratio = 강조 NF / 완화 NF
- 원시 빈도, NF, 비율 *모두* 보고.

## 6. 박사급 진단의 6원칙 반영

본 스크립트는 분석 절차에 다음 안전장치를 내장하고 있습니다.

| 원칙 | 구현 |
|---|---|
| 1. 통계적 유의성보다 상대적 패턴 | LL 결과에 "탐색적" 노트 자동 추가 |
| 2. 비평가 vs 비평가 LL의 탐색성 | `critic_vs_critic` 키에 명시 |
| 3. MI는 KWIC 정성 검증 필수 | 공기어 결과에 노트 자동 추가 |
| 4. BHR 원 데이터 + 비율 모두 | `count`, `nf`, `bhr` 모두 출력 |
| 5. 사전 + 자동 추출 병행 | `KEY_TERMS`(사전) + LL(자동) 모두 |
| 6. 예상과 어긋남에는 복수 가설 | report.txt 말미에 권고 명시 |

---

## 7. 한계와 권고

**스크립트가 *할 수 있는 것*:**
- 비평가별 어휘적 정체성의 큰 윤곽
- 동일 기표의 의미장 분기 (정성적으로 명백한 사례)
- 발화 자세의 상대적 차이

**스크립트가 *할 수 없는 것* (사용자가 보완해야 할 것):**
- KWIC 정성 검증 — `results.json`의 공기어 패턴을 원문에서 직접 확인 필요
- 검열 효과와 비평적 자세의 분리 — 시기별 정성 정독 필요
- 통계적 유의성을 일반화하는 결론

분석 결과를 *시론*으로 정확히 위치 부여하는 것이 결정적입니다.

## 8. 예시 결과 해석

테스트 코퍼스 결과의 예 (실제 사용 시 더 풍부한 패턴이 나옴):

```
[2] 핵심어 분석 (LL · %DIFF)
  >> 박용철 특유 어휘 상위 12개
     기술         LL   14.54  | %DIFF     inf  | target   7 · other   0
     영감         LL    9.35  | %DIFF  +508.7% | target  10 · other   3
```

→ 박용철에게서 **기교→기술** 전환이 정량적으로 가시화됨. 강계숙(2014)의 정성 발견의 정량적 *재가시화*.

```
[6] 통합 좌표 — 내용 차원 × 자세 차원
  김기림       내용 정체성: 형식 우선       |  자세 BHR 4.00
  임화        내용 정체성: 내용 우선       |  자세 BHR ∞
  박용철       내용 정체성: 영감 우선       |  자세 BHR 0.00
```

→ 박용철의 BHR이 영감 옹호자에게 예상되는 단언적 자세보다 *현저히 낮다*면, **예상과 어긋남**의 후보. 5장에서 복수 해석 가설(영감의 합리화 불가능성 / 시문학파의 미적 신중함 / 임화 비판에 대한 전략적 우회)을 검토해야 함.

## 9. 라이선스·인용

본 스크립트는 본 연구의 분석 파이프라인입니다. 실제 데이터를 분석하기 전에:

1. 코퍼스를 정독하여 근대 한국어 비평 어법 특유의 표지를 `BOOSTERS`/`HEDGES`/`CONNECTIVES`에 보충
2. KWIC 검증을 위해 원문 접근 환경 준비
3. 분석 결과를 *시론*으로 정확히 위치 부여하는 글쓰기 톤 유지
