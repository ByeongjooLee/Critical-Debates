# Critical-Debates: 문학비평 논쟁의 텍스트언어학적 재구성

## 연구 개요

1930년대 기교주의 논쟁(1933–1937)에 참여한 김기림·임화·박용철의 비평 텍스트를 대상으로, 코퍼스 언어학(Corpus Linguistics)의 계량적 방법론과 질적 담론분석을 결합한 혼합 방법론(Mixed Methods) 연구이다. 정규화 빈도(NF), 로그우도비(LL), 상호정보량(MI), 강화·완충 비율(BHR), 접속 표지 분포 분석, 그리고 시기별 어휘 궤적 추적을 통해 세 비평가의 담론 구조·담화 자세·핵심 어휘 사용 패턴을 계량적으로 포착한다. 분석 결과는 오형엽·강계숙·신문봉 등 기존 질적 연구의 논지를 귀납적으로 교차 검증하는 한편, 기존 연구가 공시적으로 처리한 논쟁 과정에 통시적 차원(시계열)과 매체(장르) 효과라는 새로운 분석 축을 추가한다.

## 분석 방법론

### 사용 도구

| 구분 | 도구 |
|------|------|
| 형태소 분석 | [Kiwi](https://github.com/bab2min/Kiwi) |
| 근대어 서브워드 토크나이징 | [ModernKoreanSubword](https://github.com/bab2min/kiwipiepy) |
| 분석 스크립트 | Python 3 (`gigyo_analysis.py`) |
| 출력 | `output/report.txt` |

Kiwi와 ModernKoreanSubword를 병행한 이유: 1930년대 비평 텍스트의 이형태·연철 표기·일본어 차용 표현에서 발생하는 현대 형태소 분석기의 오류를 최소화하기 위함이다.

### 계량 지표

**정규화 빈도 (NF: Normalized Frequency)**  
1,000어절당 출현 횟수. 코퍼스 규모 불균형을 제거하고 비평가 간 어휘 사용 빈도를 비교 가능하게 한다. NF가 높을수록 해당 어휘가 그 비평가 담론의 중심 범주로 기능하였음을, 낮을수록 주변적이거나 타자의 언어로만 간헐적으로 호출되었음을 의미한다.

**로그우도비 (LL: Log-Likelihood)**  
특정 어휘가 해당 비평가 텍스트에서 전체 코퍼스 대비 통계적으로 유의미하게 집중되는지를 측정한다. LL 상위 어휘는 단순 고빈도어가 아니라 해당 비평가를 다른 비평가와 변별하는 담론적 표지이다.

**상호정보량 (MI: Mutual Information)**  
두 어휘의 공기(共起) 강도를 측정한다. MI가 높을수록 두 개념이 우연적 공기 이상으로 긴밀하게 연계되어 사용됨을, 즉 해당 비평가의 사고 구조에서 개념적 결합 관계를 형성함을 의미한다.

**강화·완충 비율 (BHR: Booster-Hedge Ratio)**  
강화 표현(반드시, 결코, 분명히 등)과 완충 표현(어쩌면, ~인 듯, ~인지 모르겠으나 등)의 빈도 비율. BHR이 높을수록 단언적·확정적 담화 자세를, 낮을수록 분석적·탐색적·유보적 담화 자세를 나타낸다.

**접속 표지 분포**  
원인-결과, 대조, 예시·환언, 순접, 부연 등으로 범주화한 접속 표지의 NF 분포. 각 비평가의 논증 구조적 특성(인과적 추론, 변증법적 대립, 개념 환언 등)을 반영한다.

## 주요 분석 결과

### 비평가별 핵심 어휘 (LL 상위)

- **임화**: 낭만주의(102), 언어(101), 리얼리즘(74), 낭만(57) — 사조(思潮) 수준의 개념 투쟁 어휘장
- **김기림**: 비평(141), 비평가(58), 모더니즘(50), 과학(34) — 메타비평적·과학주의적 어휘장
- **박용철**: 인상(46), 임화(38), 효과(31), 기술(30), 변설(25) — 수용 미학적 어휘장 + 상대방 직접 거명 전략

### 담화 자세 (BHR)

- 박용철(3.010) > 임화(2.183) > 김기림(0.950)
- 임화의 BHR은 전사기(1.663) → 전개기(2.011) → 여파기(4.367)로 시계열 급증: 이념적 확신 강화 과정이 담화 자세에 반영됨

### 기교·기술 어휘의 비평가별 상이한 궤적

| 비평가 | 패턴 | 해석 |
|--------|------|------|
| 박용철 | 기술 우위 일관 → 기교 논쟁 후 소멸 | 기교는 처음부터 비판 표적어, 기술은 고유 언어 |
| 임화 | 기교 NF: 전사(0) → 전개(4.64) → 여파(0) | 기교는 논쟁 절정기의 일시적 비판 표적어 |
| 김기림 | 기술 우위 → 논쟁기 기교 역전 급증 | 상대방 언어를 자기 담론에 수용·재정립하는 과정 |

### 임화의 낭만→리얼리즘 전환 (이분할 NF 변화값)

- 낭만: -1.82 / 리얼리즘: +3.99 — 전기의 낭만주의 비판에서 논쟁기의 리얼리즘 정립으로의 이행이 어휘 수준에서 확인됨

### 임화의 내용-형식 개념 연계 (MI)

- 임화의 내용↔형식 MI = 6.90 — 세 비평가 중 유일하게 내용과 형식을 변증법적 긴장 관계 속에서 의식적으로 논의함

### 매체(장르) 효과

| 비평가 | 신문연재 BHR | 잡지비평 BHR |
|--------|-------------|-------------|
| 김기림 | 0.766 | 2.514 |
| 임화 | 3.600 | 1.359 |
| 박용철 | 3.257 | 2.495 |

김기림과 임화가 상반된 방향의 매체별 BHR 차이를 보인다는 사실은, 기존 연구에서 동질적 자료로 처리된 신문·잡지 비평 텍스트가 각 비평가에게 상이한 담화 전략을 요청하였을 가능성을 제기한다.

## 이론적 틀

### 코퍼스 기반 담론분석 — Baker (2006)

Paul Baker, *Using Corpora in Discourse Analysis* (Continuum, 2006)

빈도 분석·핵심어 분석(Keyness)·연어 분석(Collocation)·용례 분석(KWIC)을 통해 담론의 계량적 패턴을 추출하고, 이를 질적 해석과 삼각검증(Triangulation)하는 방법론적 틀을 제공한다.

### CDA + 코퍼스 언어학 통합 — Baker, Gabrielatos & McEnery (2013)

Paul Baker, Costas Gabrielatos, Tony McEnery, *Discourse Analysis and Media Attitudes* (Cambridge UP, 2013)

양적 코퍼스 분석 ↔ 질적 CDA를 순환 반복하는 9단계 프레임워크. 하향식(이론 주도)과 상향식(데이터 주도) 분석의 병행을 강조한다.

### 논증 마이닝 — Saint-Dizier & Janier (2019)

Patrick Saint-Dizier, Mathilde Janier, *Argument Mining: Linguistic Foundations* (ISTE/Wiley, 2019)

주장(Claim)–근거(Data)–반박(Rebuttal)의 논증 구조 분석, Toulmin 모델, 담론 표지 기반 논증 관계 탐지.

### 텍스트마이닝-질적 분석 통합 — Wiedemann (2016)

Gregor Wiedemann, *Text Mining for Qualitative Data Analysis in the Social Sciences* (Springer, 2016)

텍스트마이닝을 질적 분석의 대체가 아닌 보조 도구로 위치시키는 V-TM(Validation of Text Mining) 3단계 프레임워크.

## 주요 선행연구와의 관계

| 선행연구 | 분석 층위 | 본 연구와의 관계 |
|----------|----------|----------------|
| 오형엽 — 기하학적·변증법적·유기체적 문제설정 유형론 | 철학적·이론적 층위 | 세 문제설정의 차이를 BHR·접속 표지·LL로 귀납 검증 |
| 강계숙(2014) — 논쟁의 시론적 역학 분석 | 텍스트 간 대화 층위 | BHR 시계열·접속 표지 변화로 담화 자세 이동 데이터 제공 |
| 신문봉(2022) — 인식의 준거점(형식/내용/영감) 분석 | 인식론적 층위 | LL·NF·MI로 각 준거점의 어휘적 근거를 귀납적으로 재확인 |

세 선행연구는 공통적으로 공시적(synchronic) 분석에 의존한다. 본 연구는 이에 통시적 차원(논쟁 과정 내 어휘·담화 변화)과 매체 효과 분석을 추가함으로써, 기교주의 논쟁이 고정된 입장들 사이의 충돌이 아니라 논쟁 과정 자체가 각 비평가의 담론을 변화·심화시킨 동적 사건이었음을 보인다.
