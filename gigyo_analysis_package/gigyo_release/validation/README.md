# 수작업 검증 — 'ㄹ 수 있다' 의미 구분

BHR 완화 집계의 절반 이상을 차지하는 `-ㄹ 수 있다`가 이 비평 레지스터에서
완화(hedge)로 기능하는지를, 자동 규칙만이 아니라 **사람이 직접 판정**하여
교차검증한 기록이다.

## 표본
- 전체 255개 용례 중 비평가별 **층화 무작위 40개**(박용철 10·임화 20·김기림 10, 시드 42)
- 생성: `make_sample_coding.py` → 코더가 **문단 문맥**을 읽고 완화/비완화/보류 판정
- 자료
  - `suitda_sample40_coded.xlsx` — 코더가 직접 태그한 원본(엑셀)
  - `suitda_sample40_coded.tsv` — 검토용(ID·구절·자동분류·수작업판정·형태규칙·일치)

## 수작업 코딩 결과
- 완화 **2** / 비완화 **38**
- 박용철 완화 1/10 · 임화 **0/20** · 김기림 1/10
- 완화로 판정된 2개는 모두 양보·추측 형태(`짐작할 수는 있지마는`, `될 수 있으리라고`)

## 자동 형태 규칙과의 일치
- 형태 규칙(양보·추측 어미 → 완화 / 평서·관형형 → 비완화; `run_bhr_formrule.py`)이
  수작업 40개와 **40/40 일치**
- → 이 레지스터에서 `-ㄹ 수 있다`는 대부분 **제시적·관찰적 용법(비완화)**이며,
  형태가 그 기능의 신뢰할 만한 대리지표임을 시사

## 재집계 결과
- 의미 구분 BHR: 박용철 ≈ 0.45 · 임화 ≈ 1.23 · 김기림 ≈ 0.85
- 모든 `수 있다`를 완화로 센 R0(0.30·0.61·0.58)과 달리 **임화는 1을 상회**
- 따라서 "세 비평가 모두 BHR<1(유보적 수렴)"은 성립하지 않는다

## 코더 간 신뢰도 (inter-coder reliability)
두 코더(둘 다 현대문학 박사수료)가 **서로의 코드를 보지 않고** 같은 40개를 독립 코딩.
- 코더1(저자): `suitda_sample40_coded.xlsx` · 코더2(학생연구원): `suitda_sample40_coder2.xlsx`
- 일치 **40/40 (100%)**, **Cohen's κ = 1.00**
- 두 코더가 독립적으로 **동일한 2개**(`짐작할 수는 있지마는`, `될 수 있으리라고`)를 완화로,
  나머지 38개를 비완화로 판정. 대조표: `intercoder_agreement.tsv`

### 신뢰도 해석의 한계 (정직)
- **분포 치우침**: 비완화가 38/40(95%)으로 편중되어 우연기대일치 pe=0.905. κ=1.00은
  불일치가 0이라 성립하나, **단 1개만 갈렸어도 κ가 크게 떨어진다** — κ가 불안정하고 정보량이
  낮다. 더 크고 균형 잡힌 표본일수록 견고하다.
- **완전 일치의 양면성**: 경계 사례(`볼 수 있다` 제시 등)에서도 갈리지 않은 것은, 두 코더가
  **동일 분과 배경**이고 같은 코딩 지침(제시/완화 구분을 명시)을 공유했기 때문일 수 있다.
  즉 *서로의 코드엔 블라인드였으나 분석 틀에는 블라인드가 아니다.*
- 박용철·김기림 표본은 각 10개로 작다(임화는 20).
- '제시(evidential)'는 `수 있다` 기반 **부분 조작화**이며, 다른 evidential(보다시피 등)은 미포함.

## 강조 '물론' 재분류 (단일 코더)
강조 1위 `물론`은 이 레지스터에서 대부분 양보·첨가·'물론하고'(=regardless)로, 화자의 확신(강조)이
아니라 반대 논점을 인정한 뒤 뒤집는 구조다('물론 X, 그러나 Y'). 따라서 `물론`도 강조/비강조로 용법 구분하였다.
- 코딩 파일: `mullon_coding_coder1.xlsx` (전수 83개, 코더1=저자)
- 결과(코더1): 강조 유지 — 박용철 3·임화 28·김기림 12 / 비강조 제외 — 박용철 1·임화 21·김기림 18
- 재집계 BHR(완충 `수 있다` + 강조 `물론` 동시 정제): **박용철 0.44·임화 1.07·김기림 0.71**
  (임화만 >1, 상대 서열 임>김>박 불변). 재현: `python run_bhr_mullon.py`

### 한계 (정직)
- **단일 코더.** `수 있다`와 달리 제2 코더 검증이 아직 없다(후속 과제). 자동 형태규칙(`물론이다`류만
  강조)과 코더1 판정의 일치는 53%로, `물론`의 강조/양보 판정이 `수 있다`보다 더 논쟁적임을 보여준다.
- 임화 1.07은 1에 근접하여 `물론` 코딩에 민감하다(엄격 자동규칙에선 0.87). 절대 라벨('단언')보다
  상대 서열을 신뢰할 것.

## 재현
```bash
python make_sample_coding.py        # 표본 코딩지 생성(시드 42 → 동일 40개)
python run_bhr_formrule.py          # 형태 규칙 전수 재집계 + 본 수작업 40개 교차검증
```
